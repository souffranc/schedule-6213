# Расписание 6213 — подгруппа 13Б

Персональное расписание на осенний семестр 2026 года. Статический сайт/PWA: без сервера, базы данных, Docker и платных API.

## Локальный запуск (Windows / PowerShell)

Самый простой способ — дважды щёлкните `start.bat` в папке проекта: скрипт запустит локальный сервер и откроет страницу в браузере. Чтобы остановить сервер, закройте окно консоли. Если порт 8000 занят другим приложением, скрипт проверит, что именно там отвечает, и возьмёт следующий свободный (8001, 8002, …) — адрес печатается в окне. Начальный порт можно указать аргументом: `start.bat 8080`.

Вручную из папки проекта:

```powershell
py -m http.server 8000
```

Откройте http://localhost:8000. Для PWA и Service Worker нужен HTTP(S), поэтому не открывайте index.html двойным щелчком.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий на GitHub, например `schedule-6213`.
2. Загрузите в репозиторий всё содержимое этой папки (не сам ZIP).
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите ветку `main`, папку `/ (root)` и нажмите Save.
6. Через минуту сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/schedule-6213/`.

## Установка на телефон

- Android: откройте сайт в Chrome → меню → «Установить приложение» / «Добавить на главный экран».
- iPhone: откройте сайт в Safari → «Поделиться» → «На экран Домой».

## Обновление расписания

Измените `data/schedule.json`, затем увеличьте версию кэша в первой строке `service-worker.js` (например, `schedule-6213-v2`) и отправьте изменения в GitHub. При следующем открытии сайт загрузит новую версию.

## Данные и ограничения

- Источник: лист `6213` файла `ФВМ 2 курс.xls`.
- Включены занятия для 13Б и общие занятия; записи только для 13А исключены.
- Период: 01.09.2026–28.12.2026.
- Неделя 1 — короткая первая неделя 01–06 сентября; неделя 2 начинается 07 сентября.
- Время пар взято из предоставленного графика звонков.
- Учебные даты и недели сформированы по признакам `н`/`ч` и диапазонам лекций/практик в Excel. Перед использованием как официального источника сверьте спорные записи с расписанием кафедры.
